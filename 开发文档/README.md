# SGS 项目开发文档

本目录是《三国杀》MVP 程序的项目开发文档集合。**只写文档，不写代码**；
所有设计以文字、表格与结构示意描述，便于评审后再进入实现。

## 文档清单与阅读顺序

| 序号 | 文档 | 内容 | 读者 |
|---|---|---|---|
| 01 | [总体设计](01-总体设计.md) | 目标、范围、架构、技术选型、模块划分 | 全体 |
| 02 | [规则引擎设计](02-规则引擎设计.md) | 状态模型、时机系统、结算栈、询问/响应 | 引擎开发 |
| 03 | [数据模型与技能描述](03-数据模型与技能描述.md) | 牌/武将/技能的数据结构与效果原语 | 引擎 + 数据 |
| 04 | [AI 与交互设计](04-AI与交互设计.md) | 参与者接口、信息可见性、AI 分层、协议 | AI + 前端 |
| 05 | [测试与验证策略](05-测试与验证策略.md) | 测试金字塔、Golden Replay、不变量、门禁 | 全体 |
| 06 | [里程碑与风险](06-里程碑与风险.md) | M0–M5 计划、验收标准、风险与决策记录 | 全体 |

## 与规则文档的关系

- 规则依据：`../三国杀详细规则.txt`（标准版 + 军争篇 + 界限突破·标准包）。
- 本套开发文档中的一切设计都必须能追溯到规则文档的具体章节；
  规则文档中标注“存疑点”的条目，在 [06](06-里程碑与风险.md) 中登记为
  **待决策项（ADR）**，由项目明确二选一后写死。

## 目录结构约定（实现阶段）

```
SGS/
├── AGENTS.md                # 项目注意事项（提交 + 测试）
├── 三国杀详细规则.txt        # 规则基准
├── 开发文档/                 # 本目录
├── tests/                   # 文档校验与（未来）代码测试
├── 参考资料/                 # 研究底稿
└── （未来）src/              # 实现代码，不在本次交付范围
```

## 维护约定

1. 任何文档改动完成后必须创建一次 git commit（对应 `AGENTS.md` 第 1 条）。
2. 任何文档改动后必须更新并跑通 `tests/` 下的校验脚本（对应第 2 条）。
3. 设计变更需同步更新对应文档与本索引中的描述，禁止文档与实现长期背离。
