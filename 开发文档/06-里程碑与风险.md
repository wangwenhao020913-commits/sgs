# 06 里程碑与风险

---

## 1. 里程碑规划

### M0 规则与设计冻结（当前阶段）
- 交付：规则文档缺口补齐；本套开发文档；文档校验测试通过。
- 验收：`tests/run_all.sh` 全绿；规则存疑点全部登记为决策项。
- 产出物：`三国杀详细规则.txt` + `开发文档/`。

### M1 引擎骨架可跑通最小对局
- 范围：状态模型、时机枚举、结算栈、行动校验、脚本玩家。
- 内容：仅【杀】【闪】【桃】+ 无武将；无身份 1v1（2 人）；命令行。
- 验收：可完整打完一局；同种子结果一致；单元测试覆盖使用全步骤。
- 风险最高点：**结算栈与插入结算**是否正确。

### M2 标准版身份局
- 范围：108 张牌、判定、延时锦囊、无懈可击、濒死、死亡奖惩、
  身份胜负、4～8 人配置。
- 验收：Golden Replay 用例 ≥ 30 条；不变量 fuzz 无失败。
- 关键验证：无懈嵌套、目标时机、同时死亡判定。

### M3 标准版武将 + 启发式 AI
- 范围：**16 名**标准版武将（覆盖 A–I 九族机制 + J–N 顺带族）；随机 AI + 启发式 AI。
  **无界面**（沿用命令行；见 §2「MVP 范围裁剪表」的"人类 UI ⏳ M4 / 动画 ❌"）。
- 验收（**三条机械判据**，逐条定义见 `.scratch/m3-standard-heroes/spec.md` §Acceptance）：
  1. **每个机制族都有构造局面实测**——A–I 每族 ≥1 条（落点 `tests/test_hero_skills.py`）；
  2. **一局 5 人全 AI 可无人干预跑完并给出正确胜负**——固定 5 人、**32 个种子**，
     判据 = 跑完 ∧ 终局记录与身份胜负一致 ∧ 零非法应答 ∧ 可回放；
  3. **门禁全绿**——`bash tests/run_all.sh`（5 个 shell 校验 + 全部 pytest）。
- 关键验证：**逐点触发**（受 1 点伤害逐点触发；伤害减为 0 则一次都不触发）、**改判循环**、
  **求助窗口**、**失去牌后**、**目标池排除**。
- 与本节原文的两处已裁定偏离（第 0 票回写）：① "12～15 名" → **16 名**
  （数量是机制覆盖的结果、不是判据）；② 验收从一句话拆成上面三条机械判据。

### M4 可用界面 + 完整标准局
- 范围：极简 Web 界面、事件流渲染、询问应答、回放。
- 验收：人类可完整打完一局 8 人身份局；可回放复盘。

### M5 军争篇
- 范围：52 张牌、属性伤害、连环传导、【酒】、藤甲 / 白银狮子。
- 验收：属性与连环专项测试通过；AI 会使用 / 防范属性伤害。
- 注意：军争显著提高伤害上限，需要重跑平衡性相关的 AI 测试。

### 后续（非 MVP）
界限突破（宝物槽位 + 界武将）→ 国战（暗置 / 明置 / 野心家）→
联机匹配 → 搜索型 AI。

## 2. MVP 范围裁剪表

| 功能 | MVP | 理由 |
|---|---|---|
| 身份局 | ✅ | 核心玩法 |
| 标准版 108 张 | ✅ | 规则基础 |

| 联机 | ❌ | 单机跑通再谈 |
| 动画 / 音效 | ❌ | 不影响正确性 |

## 3. 风险清单与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 结算时机实现错误 | 规则不可信，全盘返工 | 先建时机枚举与栈；用官方 FAQ 建 Replay |
| 技能硬编码进流程 | 加武将越来越难 | 数据驱动 + 效果原语；禁止技能逻辑进主干；机械判据 = 源码纪律扫描（`tests/test_source_discipline.py` §5） |
| 隐藏信息泄露 | AI 作弊、回放失真 | Query 生成前强制可见性过滤 |
| 规则版本混淆 | 行为不一致 | 内容包 + 规则版本配置，显式声明 |
| 存疑点未决 | 实现反复 | 全部登记为决策项，在 `06` §4「决策记录（ADR）」与 §5「程序化约定与偏离一手」逐条裁定并落文档 |
| 非确定性 bug | 无法复现 | 单一随机源 + 事件日志 + 禁止时间/顺序依赖 |
| 范围蔓延 | 迟迟跑不通一局 | 严守 MVP 裁剪表，M1 先只做杀闪桃 |
| 数据录入错误 | 隐蔽的规则错误 | 加载期结构 + 语义校验；牌堆分布断言 |

> **ADR-011 变更说明（依据 R1-Q6）**：
> 旧文 `04` §3「AI 分层设计」的 §3.2 把"**身份推断**"列为评分要素、§3.4 要求"AI 决策必须在
> 时限内返回，超时则按放弃 / 默认动作处理"。**两条一并改判**：AI **不做身份推断**
> （面对"不知道谁是敌人"时保守 + 局面量），**也不建决策时限**（超时属接入层，归 M4）——
