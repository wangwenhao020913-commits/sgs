# SGS v0.2.0-win64 · Windows 免安装包

解压 → 双击 `SGS.exe` → 浏览器自动打开 → 开始对局。**不需要安装 Python**（3.14.4 已内嵌在包里）。
从这一版起，包内附带 **115 张武将立绘**：开局页与武将详情直接显示，缺图的武将走等大的立绘空位。

## 这一版是什么

《三国杀》的单机规则引擎 + 网页牌桌，AI 托管其余座位。

与 v0.1.0 相比：

- **武将**：121 个武将版本 / 79 名武将（v0.1.0 为 103 / 68），技能目录 261 条（v0.1.0 为 217）。
  新增群英包（「锋势」陆逊、「锋势」祢衡）、兵势篇·节包（势赵云）、始计篇（神郭嘉 / 陈震 / 骆统）、
  SP1 组（SP孙尚香 / 马良）、SP8（刘焉）、谋攻篇（谋刘赪），以及一将成名 2011 / 2014 的移动版
  与界一将成名 2011 / 2014 的移动版（徐盛 / 界徐盛 / 张春华 / 曹真 / 界曹真 / 界沮授 / 界陈群 /
  界顾雍 / 界吴懿 等）。
- **武将立绘**：115 张，按「真名 / 显示名称」组织；**不借真名**（「界关羽」没有自己的图就是空位）。
  首页与武将详情显示；**牌桌武将块不放立绘**，版式与 v0.1.0 相同。
- **演出**：雷 / 火属性伤害、失去体力、回复体力、铁索连环、阵亡，各有画面与现场合成的音效。
  只有重档演出暂停回放（雷 3 / 4 档、火 3 / 4 档、回复 3 档及以上），其余演出与记录流并行。
- **剧本模式**：作者编排的路线（网格 + 节点 + 边）、剧本存档与坏档恢复、剧本编辑器。
- **交互**：预发动、座位常驻状态标签、转化候选、判定槽、悬停卡面预览、回放页。

## 安装与卸载

- 解压到任意位置（**整个文件夹要一起留着**：`SGS.exe` 旁边的 `_internal/` 与 `pic/` 都是它的一部分）。
- 你的数据（录像、将池存档、日志）在 `%LOCALAPPDATA%\SGS\`，**不在** exe 旁边。
- **`pic/portraits/` 是武将立绘**：整目录替换即可换素材，也可以设环境变量 `SGS_ART_DIR` 指到别处。
- 卸载 = 删掉包目录与 `%LOCALAPPDATA%\SGS`，不写注册表、不开机自启、不装服务。

## 需要你知道的三件事

1. **未签名**：首次运行会弹「Windows 已保护你的电脑」——点「更多信息」→「仍要运行」。
   没有买代码签名证书，这是个人作品的常态；介意的话用源码跑。
2. **只支持 Windows x64**（Win10/11）。PyInstaller 不能交叉编译。
3. **单机**：每台电脑各玩各的一局。局域网内可以多台设备连同一台机器的服务，但各自开各自的局
   ——引擎现在只有一个人类座位，没有"两人同坐一张桌子"的模式。

## 从哪来 / 怎么重建

仓库里的 `packaging/` 是这套包的配方：`build.ps1` 一条命令重建（自备用户级 Python 3.14），
`selfcheck.ps1` 打包后跑全套无头验收，`README.md` 记了每个设计决定与已知限制。
换机器开发所需的、`git clone` 之外的东西，见同一次发布的 `sgs-dev-snapshot-0.2.0.tar.xz`。
