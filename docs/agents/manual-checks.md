# 人工档：哪些检查交还给人

**人工档**是**门禁之外**的那一档：它不进 `tests/run_all.sh`，也不向 stdin 要输入
（`tests/test_dod.py::test_the_gate_is_non_interactive` 钉住这条）。门禁只凭退出码判决，
所以人工判据必须有一个**门外的载体**——就是这份登记表 + 实机验收窗口。

本文件回答三个问题：**哪些检查交还给人**、**票面怎么声明**、**逃逸后怎么放回自动那边**。

## 票面怎么写

票头在 `Touches:` 旁写一行 `Human:`，值域只有三个：

| 值 | 含义 |
|---|---|
| `Human: 过` | 本票的人工条目已经判过并通过（窗口回「过」，或 agent 按配方走完） |
| `Human: 不适用:<理由>` | 本票不触碰任何人工条目（理由要写具体到条目编号或文件） |
| `Human: 待` | 还没判——**`Status: resolved` 的票不允许出现 `待`**（`tests/test_agent_skills.sh` 核） |

**机械核到哪一步**（`tests/test_agent_skills.sh` 的 `scan_issue_human`）：**写了就必须合法**——
值在词表内，且 `resolved` 的票不许停在 `待`、`不适用:` 必须带理由。它**不**强求每张票都写：
`.scratch/` 里有 328 张 2026-11-22 之前 resolved 的票，一刀切会整片判红。强制写在这一层之外——
票面模板（`docs/agents/skill-authoring/batch-ticket.md` 的 `Human: 待`）与 `AGENTS.md` 注意 4
都带这一行，新票照抄即有。

## 登记表

| 编号 | 交还给人的是什么 | 人看什么 | 自动侧还留什么 |
|---|---|---|---|
| **MC-01** | **界面表现**：版式、动效观感、交互手感（`tests/support/ui_smoke.mjs` 里那批视觉断言） | 验收窗口里自由玩，回「过 / 不过 + 现象」 | 3 条**机械锚**：进入处理区 / 舞台卡更新 / 弃牌；脚本顺序、比例表等静态判据（`tests/test_web_static.py`，≈1 s） |
| **MC-02** | **新武将技能的新问题**（"新技能的新问题只能靠他玩出来"） | 每做完一个武将开一个窗口，`docs/agents/acceptance-web.md` §0 | 构造局面单测、金录像、不变量 fuzz 全部照旧 |
| **MC-03** | **强度与手感**（AI 打得像不像、卡不卡） | `docs/agents/acceptance-ai.md` 的一局读数 | 统计类（胜率批 / 多种子整局）在全量档**照跑**，只是不进票档 |

**交界处的判据**（为什么是这三条，而不是别的）：交还给人必须**同时**满足三条——① **慢**
（≥30 s，或维护面 ≥1 万行）；② **人一眼能判**（表现 / 手感 / 内容，不是字节或概率）；
③ **不护不可逆契约**（字节级基准、确定性、不变量、账本计数、冻结标识符）。

三条缺一条就不许交还人。尤其：**统计类不能交还给人**（没有人会替跑 128 局胜率），它们只是
搬出**票档**、留在**全量档**——那是分流，不是交还。

## 逃逸（绊线）

出现一个"自动化本可抓住、却被人工放过"的缺陷时，按下面的顺序办：

1. **用户报障**（或窗口回「不过」）⇒ agent 复现；
2. agent 做**先红后绿**证明：补上那条断言，证明它在修复前是红的；
3. 定位它属于**哪一族**（见 `开发文档/05-测试与验证策略.md` §7 的族表）；
4. 若那一族被移出过**票档**（或在 MC 表里）⇒ agent **提议**把它放回票档，并改族表；
5. **用户确认** ⇒ 写回本文件 / 族表，票面 `Human:` 与 `## Answer` 记一笔。

**上界纪律：一次是事故，同类第二次才是设计错误。** 单次逃逸只放回**那一族**（成本 = 那一族的
时间，不是一次全量）；同一族第二次逃逸，才扩大它的触发面（从"相关票"扩到"所有票"）。

**反过来也成立**：某一族连续两个 effort 一次没红、且人工条目一直判「过」⇒ 可以在收口时提议
把它从票档降级。降级与升级都走同一张表、同一次确认，不自作主张。

## 改这张表的时候

- 加人：必须写清 ①②③ 三条判据各自怎么满足，以及**自动侧还剩什么**；
- 减人（放回自动）：必须指明它回到**哪一档**（票档 / 全量档），并给出票档时间的实测；
- 这张表变动 ⇒ 同步 `AGENTS.md` 注意 2 的族表指针与 `开发文档/05`（§7「门禁与交付标准」）；
  `GLOSSARY.md` 的 **人工档** 条目只写定义，不写条目清单（术语表不承担账目）。
