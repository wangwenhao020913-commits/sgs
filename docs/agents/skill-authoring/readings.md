# 技能文本的读法（Readings）

**真源不是这份文档**。默认读法住在 `06`（§5「程序化约定与偏离一手」），逐条取证住在
`参考资料/技能描述歧义核查.md`。本文件只做两件事：**告诉你去读哪几行**，以及**规定读完必须
产出什么**。抄结论到这里必然漂移，所以这里一条结论都不抄。

## 1. 读哪三处

| 读什么 | 在哪 | 怎么找 |
|---|---|---|
| 默认读法（一）：区域与数量 | `06`（§5「程序化约定与偏离一手」） | `.venv/bin/python tools/ledger_index.py --grep 默认读法` |
| 默认读法（二）：角色、回合与数值 | 同上 | 同上 |
| 默认读法（三）：限定词决定触发粒度 | 同上 | 同上 |
| 单条技能的既有裁定 | 同上 | `tools/ledger_index.py --grep <技能名/票号>` |
| 43 条歧义的逐条取证（含 8 条"未找到权威来源"） | `参考资料/技能描述歧义核查.md` | 直接读 §3–§7 |
| 版本权威 | `06`（§5「程序化约定与偏离一手」） | `--grep 技能文本以 OL 现行为准` |

**读法表的每一行都必须指到上面某一处**（账本行关键词或歧义表编号）。指不到 ⇒ 停（判据 A2）。

## 2. 必须产出的「读法表」

票面里逐技能写这一张表，**五行缺一行不许进下一步**：

| 行 | 问 | 写什么 |
|---|---|---|
| 回合 / 阶段归属 | 牌面写的是谁的回合、谁的阶段？没写谁 ⇒ 默认读法（二）④ | 「自己的回合」/「每个回合」/「别人回合」+ 依据 |
| 牌的来源区域 | 「一张牌 / 任意张牌 / 装备牌 / 手牌 / 区域里的牌」各指哪些区？ | 手牌 / 装备 / 判定 的组合 + 依据 |
| 指代 | 「其 / 该角色 / 另一名其他角色 / 其中 / 这些」各指谁？ | 每个代词一行，写明先行词 |
| 数值与次数 | X 怎么算（动态/静态）、+N 加在哪、次数上限怎么表达 | 数值口径 + 依据 |
| **触发粒度** | 有没有「一张 / 1 点」这类限定词 | **逐张逐点** 或 **逐事件一次** + 依据 |

## 3. 高频词速查（词 → 去账本搜什么）

| 牌面用词 | 搜这个关键词 | 备注 |
|---|---|---|
| 任意张 / 任意数量 / 至多 | `默认读法（一）` | 下限从 1 起（不含 0）；「至多」= 上限 + 可放弃 |
| 一张牌 | `默认读法（一）` | 牌前没区域限定 ⇒ 手牌 + 装备区 |
| 装备牌 | `默认读法（一）` | 手牌 + **装备区**里的装备牌（特殊，含手牌） |
| 区域里 / 区域内 | `默认读法（一）` | 手牌 + 装备 + 判定 |
| 手牌 | `默认读法（一）` | 手牌区（不含装备） |
| 使用 / 打出 | `默认读法（一）` | **不看区域**，只看"能不能执行这个动作"（可打装备牌、可用虚拟牌） |
| 一名角色 / 其他角色 / 另一名其他角色 | `默认读法（二）` | 含自己 / 不含自己 / 排除两个 |
| 回合 / 阶段（没写谁的） | `默认读法（二）` | 仅自己的回合；「1 名角色的回合」= 每个 |
| X（存活角色数等） | `默认读法（二）` | 动态量，每次取值按当下重算 |
| 一张 / 1 点（限定词） | `默认读法（三）` | 逐张逐点；无限定词 ⇒ 逐事件 |
| 技能失效 | `技能失效不作用于装备牌` | 失效率只覆盖武将技能 |

表里所有结论**都在账本**；这张表只是索引，别把它当裁决依据——有冲突时以账本那一行为准。

## 4. 版本权威

- 现行一切以 **三国杀 OL 现行文本**为准（账本「技能文本以 OL 现行为准」）。
- 移动版 / 台服文本与 OL 有实质差异时：**不改实现**，在账本行写清差异（判据 A1）。
- 将来引入移动版按版本并存处理；当前不实现。

## 5. 什么时候必须停

- 上面五行读法表里任何一行**指不到账本行** ⇒ 停（A2）。
- 同一句牌面能读出两种**结算后果不同**的意思 ⇒ 停（D1）。
- 一手文本自相矛盾（前提限定 A、后句判 B）⇒ 停（A3）。
- 标 / 界同短 id 但文本不同，且差异会影响行为 ⇒ 停（A4），除非差异已在声明里显式区分。

停手要交的八项见 `docs/agents/skill-authoring.md` 第 5 节。
