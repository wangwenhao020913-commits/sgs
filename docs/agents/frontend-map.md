# 前端地图（Frontend Map）

`tools/sgs_web/static/` 的导航图：**只回答"改哪份文件"**，不复述产品行为。行为真源是
`开发文档/04-AI与交互设计.md`、各 effort 的 spec 与 `tests/`；脚本清单的**唯一真源**是
`index.html` 的 `<script src>` 顺序（页面与烟测共用）。下表按同一顺序解释职责，顺序判据
仍只在 `index.html` 与 `tests/test_web_static.py`。
